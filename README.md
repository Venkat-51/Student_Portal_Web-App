# Student Portal Web Application

A web-based student management platform developed using Django that enables students and administrators to manage academic activities efficiently. The system provides features for posting doubts, viewing announcements, and managing courses and subjects.

## 🚀 Live Demo
https://student-portal-web-app.onrender.com

## 🚀 Features

### Student Features

* User Registration and Login
* Ask Questions / Post Doubts
* View Announcements and Notices
* Access Academic Resources
* Manage Profile Information

### Admin Features

* Manage Students
* Add and Manage Courses
* Add and Manage Subjects
* Post Announcements
* Monitor Student Activities

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/student-portal.git
```

### Navigate to Project

```bash
cd student-portal
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

**Windows**

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Server

```bash
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000
```
